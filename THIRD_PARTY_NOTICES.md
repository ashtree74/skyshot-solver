# Third party materials

Rust dependencies retain the licenses in their respective source distributions.
`Cargo.lock` identifies the versions used by this snapshot.
`tools/package_cli.py` generates a target-specific Cargo dependency inventory and
copies full license/notice texts into each candidate's `third_party/`, together
with the build toolchain's Rust standard-library copyright notices. The graph
includes normal and build dependencies, conservatively retaining host build
tools; dev-only dependencies are excluded. Review the inventory and native
runtime obligations for each platform before a public binary release.

The crates.io archive for `rstar 0.12.2` omits its declared license texts. The
version-specific supplement in `third_party/rstar-0.12.2/` preserves the upstream
MIT and Apache texts from the exact source commit recorded in the crate. Its
README records provenance and hashes. Those texts are not relicensed by Skyshot.

`third_party/rust-1.95.0/` supplies the exact compiler-source root license texts
when a rustup installation omits them. The actual toolchain still supplies its
library copyright notice. Its README records the upstream commit and hashes;
the supplement is only used with Rust 1.95.0. CI pins this accepted toolchain.

The panorama WCS fixture is synthetic and generated by `bench/panorama_wcs_fixture.py` using Astropy/WCSLIB. Those tools are required only to regenerate it; they are not bundled or needed to run the Rust tests.

No D80/Gaia catalogue, production index, training dataset or model weight is
included in Git. Separately prepared local data archives contain selected index
runtime files and the sanitized LGQ-GD export, with their own source inventory,
attribution, model card and terms record. Their terms are separate from Apache
2.0 on the implementation. See
`docs/DATA.md` and `docs/DATA-PROVENANCE.md`; no redistribution grant is claimed.

The two pre-existing manuscripts are covered by `research/LICENSE` (MIT); moving their license notice does not withdraw their earlier grant.
